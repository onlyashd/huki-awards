# Huki Awards

Plataforma de votação personalizada para premiações de jogos, integrando-se com a API do IGDB para
busca de metadados e utilizando o Discord para autenticação.

<details>
<summary>English</summary>

> A customized voting platform for game awards, integrating with the IGDB API for metadata retrieval
> and using Discord for authentication.

</details>
